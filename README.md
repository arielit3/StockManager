# StockManager

StockManager es un sistema de gestión de inventario desarrollado en C# para administrar productos físicos y virtuales, permitiendo controlar sus cantidades, características y disponibilidad de forma organizada y precisa.

El sistema está diseñado para facilitar la administración de productos y proporcionar un control adecuado sobre las existencias del inventario.

## Características

* Registro de productos.
* Gestión de productos físicos.
* Gestión de productos virtuales.
* Consulta de productos.
* Actualización de información.
* Eliminación de productos.
* Control de cantidades y existencias.
* Visualización del inventario.
* Diferenciación entre productos físicos y virtuales.
* Validación de información.
* Administración general del inventario.

## Tipos de productos

### Productos físicos

Son productos que representan artículos tangibles y requieren un control de existencias físicas.

Ejemplos:

* Computadoras
* Teléfonos
* Accesorios
* Ropa
* Herramientas

### Productos virtuales

Son productos que no requieren almacenamiento físico y pueden ser distribuidos mediante medios digitales.

Ejemplos:

* Licencias de software
* Suscripciones
* Cursos digitales
* Videojuegos digitales
* Contenido descargable

## Funcionamiento

StockForge permite administrar un conjunto de productos mediante diferentes operaciones de gestión.

Cada producto contiene información propia y puede pertenecer a uno de los tipos principales del sistema: producto físico o producto virtual.

Los productos físicos manejan información relacionada con sus existencias, mientras que los productos virtuales permiten administrar elementos que no requieren almacenamiento físico.

La separación de estos tipos permite que cada producto pueda tener comportamientos y características específicas sin perder una estructura común dentro del sistema.

## Objetivo

El objetivo de StockForge es proporcionar una herramienta que permita gestionar un inventario de productos físicos y virtuales de manera organizada, facilitando el control de existencias y la administración de la información relacionada con cada producto.

El proyecto también busca aplicar conceptos de C# y Programación Orientada a Objetos en un escenario práctico relacionado con la gestión de inventarios.
